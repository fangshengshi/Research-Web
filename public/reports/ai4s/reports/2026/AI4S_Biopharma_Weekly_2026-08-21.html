二、本周概念补给站

承接上期 DBTL、主动学习、平台 vs 资产

Foundation model vs World model

基础模型主要学习表示、生成和单任务预测；世界模型更强调“状态如何随时间和干预演化”。在药研中，后者理论上可做虚拟扰动实验。

最易误判：多模态拼接 ≠ 动态因果模拟。要看时序扰动、跨细胞类型泛化和外部实验。

R&D OS：为什么结构化实验数据是 AI 前置条件？

药企数据散落在仪器、ELN、LIMS、表格和个人经验。R&D OS 把实验计划、样本、条件、结果和版本串成可查询、可审计的数据链。

护城河：工作流嵌入 + 数据迁移成本 + 权限/审计，而非模型本身。

预测产品为什么不能直接按药物资产估值？

筛选模型、毒性 atlas、virtual cell 是决策工具；药物资产还要经过药效、安全、可开发性、CMC 和临床证据。

平台验证：客户付费、复用、命中率、节省成本。资产验证：PCC、IND、人体安全与疗效。

六、本周技术趋势：用投资问题解释

Virtual cell 现在值得按“下一个 AlphaFold”估值吗？

还不够。AlphaFold 有明确、可独立验证的结构预测任务；virtual cell 同时涉及状态、时间、干预、上下文和多尺度因果。当前应按高潜力平台看，等外部 benchmark 和 prospective wet-lab。

为什么 R&D OS 可能比单点 AI 模型更有护城河？

实验数据迁移、schema、仪器连接、权限、版本和审计一旦嵌入日常流程，替换成本很高。模型可以更换，组织历史与工作流上下文更难迁移。

AI 模型产品按量收费意味着什么？

AQPotency 按 protein–ligand pair 定价，意味着 scientific model 从项目制走向 API 化；若模型有效，单位经济学可放大，若不稳定，低价 API 也会迅速暴露缺乏复购。

为什么本周更看重实验数据而不是参数量？

ProteinDPO、DeepCyte、GenScript、VectorBuilder/Lir 都指向同一件事：真正难的是高质量实验反馈、机制数据、制造约束和长期客户数据。

七、精选研究与证据｜3 篇

不为凑数加入弱预印本
ProteinDPO：实验数据如何训练“模型偏好”？

约 180 万条实验稳定性测量被用于偏好式对齐。作者报告模型在稳定性预测上达到任务专用模型竞争水平，并在 H5N1 血凝素上提升热稳定性同时保留抗体识别。

投资意义：通用蛋白模型可被专有实验数据快速拉向产业目标；实验反馈可能比预训练更稀缺。局限：不能从一个属性和一个抗原实例外推到全部治疗蛋白。

Nature Methods 原文

PASTA：空间多组学测量成本下降，对 AI4S 为什么重要？

PASTA 用 tyramide-oligonucleotide amplification 将蛋白和 RNA 检测整合到循环成像流程，可用于 FFPE 样本。

投资意义：AI4S 不只需要模型，也需要可规模化、标准化、进入临床样本的高质量标签；测量成本下降会扩大 virtual cell 和病理基础模型的数据供给。

Nature Methods 原文

Nature Methods：LLM 正在压低科研单点软件的开发门槛

作者认为 LLM 代码生成已足以让科学家更快构建定制工具。投资含义：轻量分析/可视化工具的技术壁垒下降，更值得估值的是数据、工作流、验证、分发和合规；同时 vibe coding 抬高科研软件 QA 价值。

十、本周学会了什么

  • Virtual cell 的下一阶段是能表示状态、时间和干预的 world model。
